================================================================================
        基于 RAG 的知识库问答系统  ——  项目说明 & 运行手册
================================================================================


【零】一句话说清这个项目是干什么的
--------------------------------------------------------------------------------
你有一个 Markdown 文件（15 个 AI 基础概念），想让 AI 只根据这份文件回答问题，
并且像 DeepSeek 官网那样一个字一个字地把答案"打"出来，还能像微信一样保留
多个历史对话。

本项目就是把这件事做出来：
    你的 md 文档  →  存进向量数据库  →  AI 先检索再回答  →  网页上逐字显示


【一】先看目录，每个文件是干什么的
--------------------------------------------------------------------------------
Agent_Prompt/
├─ pyproject.toml                 项目依赖清单（LangChain、FastAPI 等）
├─ RAG知识库问答系统-答辩.pptx      答辩用的 PPT
├─ 项目说明-如何运行.txt            本文件
└─ src/                           ★ 所有代码都在这里
   │
   ├─ main.py                     【核心·你的 RAG Agent】
   │                              负责：加载向量库、定义检索工具和 6 个外部工具、
   │                              创建 Agent、配置 system_prompt。
   │                              这是"大脑"，但它只能在命令行里跑。
   │
   ├─ .env                        存放 API_KEY 和 BASE_URL（大模型的钥匙）
   ├─ CHROMA_DIR/                 向量数据库（文档切碎后的"记忆"，自动生成）
   ├─ data/15个高频AI基础概念....md  你的知识库原文
   ├─ chat_history.json           命令行版 main.py 的历史记录
   │
   ├─ backend/
   │   ├─ main.py                 【核心·后端服务】
   │   │                          负责：把 main.py 的 Agent 包装成网页接口、
   │   │                          SSE 流式推送、多会话管理、托管前端页面。
   │   └─ data/sessions.json      网页版的对话历史（多会话存在这里）
   │
   └─ frontend/                   【核心·前端页面】
       ├─ index.html              页面骨架：顶栏、左侧历史栏、中间对话区、底部输入框
       ├─ style.css               样式：配色、卡片、深浅主题、弹窗
       ├─ app.js                  交互逻辑：发送消息、接收流式数据、打字机效果
       ├─ markdown.js             Markdown 渲染器：把 **加粗**、代码块之类变成好看的样式
       └─ vendor/axios.min.js     通信库 axios（已下载到本地，断网也能用）

三者的关系：
    frontend（页面）  --HTTP/SSE-->  backend（服务）  --函数调用-->  main.py（Agent）


【二】怎么跑起来（三步）
--------------------------------------------------------------------------------
前提：电脑上已经装好 Python 环境（本项目用 .venv 虚拟环境，里面依赖都装好了）。

第 1 步：打开 PowerShell，进入项目目录
    cd d:\heima\Agent_Prompt

第 2 步：启动服务（复制下面这行，回车）
    .\.venv\Scripts\python.exe -m uvicorn backend.main:app --app-dir src --reload --port 8010

    启动成功的标志（屏幕上会出现这几行）：
        [backend] 正在加载 RAG Agent 与向量库 ...
        已加载已有向量库
        [backend] RAG Agent 加载完成
        INFO:     Uvicorn running on http://127.0.0.1:8010

    注意：
      · 第一次运行会看到"第一次构建向量库..."，会慢一点（要计算向量），
        之后再启动就是"已加载已有向量库"，秒开。
      · 这一行命令别关，关掉窗口服务就停了。

第 3 步：打开浏览器，访问
    http://127.0.0.1:8010

    出现深色标题栏 + 输入框 + 左侧历史栏，就成功了。

（另一种启动方式，效果一样）
    cd d:\heima\Agent_Prompt\src
    ..\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload --port 8010


【三】页面怎么用
--------------------------------------------------------------------------------
· 底部输入框：打字，按 Enter 发送（Shift + Enter 是换行）
· 输入框变成转圈 = 正在生成，此时按钮是禁用状态
· 左下角会出现"■ 停止生成"，不想等了可以点它
· 左边历史栏：点"开启新对话"开始新的；点历史条目切回旧对话；鼠标移到条目上
  右边会出现垃圾桶图标，点击可删除（有确认弹窗）
· 右上角：月亮/太阳图标切换深色浅色；"清空对话"删除当前这条对话
· 刷新页面不会丢记录，会自动打开最近一次对话


【四】按一次"发送"，背后发生了什么（通俗版）
--------------------------------------------------------------------------------
1. 你在网页输入框打"什么是 Token？"，按 Enter
2. app.js 把它发给后端：POST /chat
3. backend/main.py 收到后：
     · 找到（或新建）这个会话，把你的问题存进 sessions.json
     · 先回一条 {"type":"start"}，告诉前端"会话准备好了"
     · 把这个问题交给 main.py 里的 Agent
4. Agent（大模型）判断：这是问 AI 概念 → 应该调用 search_handbook 工具
5. search_handbook 去 Chroma 向量库里检索，找出最相关的 4 段资料
6. Agent 拿着这 4 段资料，一个字一个字地生成答案
7. 每生成一个字，backend 就通过 SSE 推给网页一条 {"type":"token","content":"字"}
8. app.js 收到就立刻显示在屏幕上 → 你看到的"打字机效果"
9. 回答完，backend 把完整答案存进 sessions.json，再发一条 {"type":"done"}

一句话总结：
    前端负责"显示"，后端负责"搬运"，main.py 里的 Agent 负责"思考"。


【五】出问题了怎么排查
--------------------------------------------------------------------------------
问题：浏览器打不开 / 转圈没反应
    检查：第 2 步那个窗口是不是关了？里面有没有红色报错？

问题：提示端口被占用（address already in use）
    原因：8000 或 8010 被别的程序占了。
    办法：换一个端口，比如把命令里的 8010 改成 8011，然后浏览器访问
          http://127.0.0.1:8011 即可（前端会自动同源访问，不用改代码）。

问题：回答报错 / 提示 API 相关错误
    检查：src/.env 里的 API_KEY、BASE_URL 是否正确、是否欠费。

问题：问了知识库里的概念，但回答不像来自知识库
    原因：src/main.py 第 194 行的工具列表里漏了 search_handbook，
          向量库虽然建好了，但 Agent 手上没有这个工具，只能靠模型自己发挥。
    解决：把第 194 行改成下面这样，然后重启服务：
          tools = [search_handbook, get_month, get_holidays, get_weather,
                   get_word, get_food, get_answer]

问题：想停止服务
    在那个运行窗口里按 Ctrl + C。
